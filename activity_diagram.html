Alur Autentikasi Pengguna & Keamanan Sesi: Validasi token CSRF form, pengecekan akun di tabel users, verifikasi password bcrypt, regenerasi ID sesi untuk mencegah Session Fixation, dan pengalihan ke dashboard sesuai role (Admin, Guru, Siswa, Wali Kelas, Kepala Sekolah).

1. Input Kredensial

Pengguna menginput Username / NIS / NIP dan Password pada halaman /auth, lalu submit form dengan token CSRF.

2. Verifikasi Backend

Sistem memverifikasi status akun aktif dan kecocokan password dengan password_verify(). Jika gagal, redirect kembali dengan pesan flash.

3. Resolusi Sesi & Role

Sistem meregenerasi sesi, menyimpan identitas pengguna, dan mengarahkan ke URL role spesifik (/admin/dashboard, /guru/dashboard, /siswa/dashboard).

Alur Guru: Presensi Mandiri & Kelola Nomor WhatsApp: Guru dapat mengatur nomor WhatsApp aktif sendiri melalui modal popup, serta melakukan presensi jam masuk dan jam pulang mandiri dari dashboard dengan konfirmasi notifikasi WhatsApp otomatis.

A. Pengaturan Mandiri Nomor WhatsApp

1. Guru klik tombol 'Ubah / Tambah Nomor WhatsApp' di kartu profil.

2. Modal #modalNoHpGuru muncul.

3. Guru memasukkan nomor HP (misal: 081234567890).

4. Controller membersihkan karakter non-digit dan menyimpan ke kolom no_wa & no_hp.

B. Presensi Mandiri (Masuk / Pulang)

1. Guru klik tombol 'Presensi Masuk' → sistem catat jam masuk dan kirim WA konfirmasi.

2. Saat jam pulang, tombol berubah jadi 'Presensi Pulang'.

3. Sistem memeriksa batas jeda minimal 10 menit, mencatat jam kepulangan, dan mengirim WA kepulangan.

Alur Asisten Pintar AI Chatbot (Live DB RAG): Menggabungkan kecerdasan buatan LLM (NVIDIA, Gemini, OpenAI, DeepSeek) dengan pembacaan database faktual sekolah (rekap absensi, jadwal mengajar/belajar, dan data profil) secara otomatis sebelum menghasilkan balasan.
User Prompt → Context Extractor (DB Siswa/Guru/Jadwal) → System Prompt Builder → Cloud LLM API → Chat Response

Sistem menjamin AI memberikan jawaban akurat tanpa halusinasi karena data kehadiran siswa, rekapitulasi guru, dan jadwal pelajaran hari ini disuntikkan langsung dari basis data sebelum API LLM dipanggil.

Alur Sinkronisasi Alpha Otomatis: Saat waktu sistem melewati batas toleransi kehadiran jam 07:00:00 WIB, sistem otomatis menandai siswa dan guru yang belum hadir dengan status Alpha (3). Jika mereka datang kemudian dan scan QR, sistem cerdas meng-update record Alpha menjadi Hadir / Terlambat.
Alur Kelola Master Siswa & Kontak Orang Tua: Admin mengelola identitas siswa, kelas, barcode ID, serta nama orang tua dan nomor WhatsApp orang tua. Tabel data dilengkapi tombol WhatsApp wa.me/62... untuk obrolan langsung.
